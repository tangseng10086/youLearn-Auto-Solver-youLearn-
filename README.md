## 💡 项目背景

在处理 CCZU的youLearn 平台的课后作业时，我没找到成册答案，就利用软件自带的bug写了这个脚本

## ✨ 亮点

### 🎨 视觉：iOS 液态玻璃 UI（如果有大佬有更好的UI可以提issue）

- **Glassmorphism 设计**：高模糊度、高饱和度的磨砂玻璃效果，完美适配 iOS 原生感(这个是gemini自己夸自己的)。
- **动态交互**：支持面板自由拖拽，实时日志输出，让自动化过程尽在掌控。
- **高光细节**：内置模拟物理高光层，具备极佳的视觉深度感（依旧gemini自夸）。
- **壁纸自定义** ：挑一张自己喜欢的图片，base64编码后写在url上即可（这点我没在ui上写是因为感觉挡住了不好看）

### ☢️ 技术：核武级物理刷新

- **物理重置**：针对单页面应用（SPA）设计，通过物理级 `location.reload()` 彻底清除内存死锁，确保脚本注入成功率 100%。
- **状态持久化**：利用 `sessionStorage` 实现跨页面记忆。脚本刷新前是什么状态，醒来后依然是什么状态，无需重复点击。

### 📡 跨域指挥系统

- **主从架构**：利用`postMessage` ,采用 `Top <-> Iframe` 跨域对讲机模式。主页面全局指挥，Iframe 埋头干活，实时战报回传。
- **全题型支持**：覆盖 **选择、判断、填空** 三大主流题型（仅CCZU，如果有其他题型不影响及格的话就自行开发吧），支持模拟真实输入流越过AunglarJS框架（DispatchEvent）。

## 🛠️ 功能清单

- [x] **智能控制**：面板自带“开始/暂停”物理开关（只能以小章节为单位暂停）。
- [x] **精准打击**：支持 `homework` 白名单过滤，只刷你指定的章节（CCZU的不用自己再调了，我已经写好了，就是不知道有没有用，我的题都刷着做完了，可以自己试试）。
- [x] **防检机制**：带有题目间的停顿（等页面）。
- [x] **半自动翻页**：完成任务后自动点击下一节，全流程无人值守（如果出先bug，可以试着手动点击一下或者刷新）。
- [x] **记忆功能**：刷新页面后自动恢复运行状态。

## 🛠️ 安装说明

1. 确保你的浏览器已安装 [Tampermonkey](https://www.tampermonkey.net/) 插件。
2. 创建一个新脚本，将本项目中的 JS 代码完整复制并粘贴进去。
3. 保存并启用脚本。
