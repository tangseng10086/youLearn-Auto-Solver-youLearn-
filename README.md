# 🚀 youLearn-Auto-Solver (youLearn 答题小助手)

一个基于原生 JavaScript 编写的 Tampermonkey（篡改猴）脚本，旨在实现 youLearn 平台的目自动识别与作答。~~（单页面是因为我累了，以后再写翻页吧）~~(已经完成了了翻页的功能，但是需要你从未提交过每一页)

## 💡 项目背景

在处理 CCZU的youLearn 平台的课后作业时，我没找到成册答案，就利用软件自带的bug写了这个脚本

## ✨ 核心特性

- **👀 哨兵探测机制 (Sentinel Pattern)**：告别传统的硬延时等待。脚本内置 `setInterval` 轮询探测，识别网页元素的加载状态（其实是刚开始就这么写的，懒得测试不用这个行不行了），DOM 加载完毕即刻开工，绝不浪费一秒钟。
- **⏱️ 人性化异步流控 (Async/Await)**：彻底摒弃嵌套地狱与同步阻塞。采用 `Promise` 包装的延迟函数，控制点击频率与网页响应等待时间，确保每一步 DOM 操作的连贯性与准确性（视觉上比较丝滑）。
- **🎯 题型动态调度**：通过提取不同题型的特有 HTML 标识（如 `ol li` 与 `span.controls`），实现同一页面的智能分发处理，防止异步记载的自定义标签难以控制加载识别时间

## 🛠️ 安装说明

1. 确保你的浏览器已安装 [Tampermonkey](https://www.tampermonkey.net/) 插件。
2. 创建一个新脚本，将本项目中的 JS 代码完整复制并粘贴进去。
3. 保存并启用脚本。

## 🚀 运行逻辑与演示

本脚本主要作用于 youLearn 的题目内容框架（`iframe` 内部，匹配规则为 `*://centercourseware.sflep.com/*`）。

1. 手动登录 WeLearn 并进入具体的测验页面。
2. 脚本会自动唤醒，控制台输出 `成功进入iframe`。
3. 脚本开始自动识别题型(其他的没写是因为我学校不需要做)：
  - **选择题**：自动遍历 A/B/C/D 选项，通过监听 DOM 属性变化（`class` 中是否包含 `correct` 标识）锁定正确答案并进入下一题。
  - **判断题**：针对判断题的特殊 DOM 结构重新定位，自动验证 True/False 选项。
  - **填空题**：针对AngularJS框架，实现了响应填空题的信息（预留接口，支持扩展模拟键盘输入事件 `dispatchEvent`）。
4. 当前页面题目清空后，控制台打印完成提示。
5. ~~手动点击~~自动跳转下一页，脚本自动复活，开启后面的题目（但是假如中间有题目提交过的，需要手动跳转）。

## 🧠 技术细节与踩坑记录

对于想要基于此脚本进行二次开发的同学，请注意以下几点：

- **Iframe 隔离限制**：由于 WeLearn 的外层导航（Index）与内容展示（Iframe）通常属于不同环境，本脚本选择在 Iframe 内“专注做题”。如需实现全局全自动翻页，需引入 `window.postMessage` 进行跨源通信（Cross-Origin Communication）。
- **DOM 污染**：在遍历选项进行正误校验时，切记将校验目标锁定在当前点击的节点上，避免发生“点击 B 选项却校验 A 选项状态”的逻辑死锁。
- **题目过滤**：可以针对自己的学校进行过滤题目，这里没有筛选，只是让遍历，为了多刷一点时长
